# PIRLS 智慧閱讀素養評量平臺 — 教師操作手冊

本手冊為國小 3～6 年級國語文教師、閱讀推動教師與教學團隊設計，引導您快速上手 PIRLS 人機協同命題、班級測驗派發、紙筆雙面列印與 AI 智慧診斷回饋。

---

## 一、系統架構與角色分工

| 角色 | 預設帳密 / 進入方式 | 核心權限 |
| :--- | :--- | :--- |
| **系統管理員** | `admin` / `admin123` | 審核教師帳號申請、全校班級與題庫總覽 |
| **認證教師** | 線上申請待審核（登入：`/login`） | 班級管理、批次產生命題、自編/微調題庫、派卷、A4列印、Excel匯出 |
| **受測學生** | 教師派發之帳號密碼 | 班級線上測驗、雙欄字級縮放閱讀、查看個人雷達圖與能力證書 |
| **自學訪客** | 首頁點選【開放自學區】（免登入） | 自由選讀公開文本、自訂暱稱測驗、即時獲得四維能力雷達圖 |

## 二、教師日常操作核心四部曲

### 第一步：班級建立與學生帳密一鍵批次生成
1. 登入教師工作台（`/dashboard/teacher`）。
2. 點擊「**新增班級**」，輸入班級名稱（例如：`四年忠班`）、年級（`4` 年級）與學年度。
3. 於該班級卡片點擊「**學生名冊**」，輸入欲生成的學生人數（例如：`25` 人）。
4. 系統自動產生：
   - 帳號格式：`stu_2026_01` ～ `stu_2026_25`
   - 安全隨機密碼或統一初始密碼
   - 座號 1～25 號對應
5. 點擊「**列印/下載學生帳密條**」，直接裁切發給學生於電腦教室或平板課堂使用。

---

### 第二步：AI 人機協同命題與試題微調
1. 進入「**AI 命題新試卷**」（`/dashboard/teacher/create`）。
2. 選擇命題模式：
   - **模式 A（AI 主題自動生文）**：輸入主題（如：`台灣黑熊與森林保育`）、文體（文學性故事／訊息性科普說明文）、目標年級（3～6年級）。
   - **模式 B（貼上自選/課本文章）**：貼上校本教材或國語課文（800～1,200 字），AI 自動解析段落並提煉試題。
3. 勾選「**生成非連續性科學圖表**」，AI 將自動產生純向量 SVG 圖表（如：生命週期圖、種子傳播循環圖、因果構造圖）。
4. 點擊「**開始生成 PIRLS 題本**」，30 秒內產出雙欄預覽：
   - **左側**：800～1,200 字長文與非連續性圖表。
   - **右側**：四層次試題卡片（L1 提取、L2 推論、L3 詮釋、L4 評估），清晰標示 1/2/3 階梯配分。
5. **人機協同微調**：教師可點擊任意題目修改題幹文字、更換選擇題選項、調整 Rubrics 評卷規準關鍵線索。
6. 點擊「**儲存至我的題庫**」。

---

### 第三步：雙場景派卷（班級測驗 vs 開放自學）
1. 進入「**我的題庫**」（`/dashboard/teacher/test-papers`）。
2. 在目標試卷點擊「**指派**」按鈕：
   - **班級測驗**：勾選指定受測的班級（學生登入後立即顯示於個人工作台）。
   - **測驗安全碼**：選填安全密碼（例如：`2026PIRLS`），防止非本科堂學生隨意進入。
   - **開放自學區**：若希望全校其他班級或訪客也能自由練習，勾選「**同時公開至開放自學區**」。

---

### 第四步：A4 紙筆雙面列印與實體課堂施測
若學校電腦教室時段不足，可直接進行實體紙筆考試：
1. 於試卷卡片點擊「**A4**」或在成績頁點擊「**A4 學生卷**」（`/print/[id]`）：
   - 自動適配標準 A4 尺寸（邊界 1.5cm）。
   - 包含自然段落編號、科學插圖、選擇題圈選格式。
   - 簡答題附設 **2～4 行書寫橫線**。
2. 點擊「**A4 解答卷**」（`/print/[id]?showAnswers=true`）：
   - 提供給授課教師或閱卷小組。
   - 簡答題展開「**IEA 官方雙位數代碼規準表**」（Code 30/20/10/11/79/99）。

## 三、成績診斷、國際量尺與 Excel 匯出

### 1. 全班五大基準分佈落點
登入後進入試卷「**成績**」頁面（`/dashboard/teacher/test-papers/[id]/results`）：
- **全班平均國際量尺分數**（對齊國際常模 Mean 500、SD 100）。
- **五大基準分佈長條圖**：
  - 👑 **高級基準 (625+)**：卓越深層思維與批判反思。
  - 🌿 **高基準 (550～624)**：良好推論因果與文本證據支持。
  - 🌊 **中等基準 (475～549)**：掌握字面情節與基礎推論。
  - 🍂 **低基準 (400～474)**：字面訊息提取能力。
  - 🛡️ **未達低基準 (<400)**：長文閱讀負荷較大，需個別化鷹架。
- **四層次能力掌握率長條**（快速檢視全班在 L3 詮釋 或 L4 評估 是否有集體盲點）。

### 2. 學生個人專屬診斷書（另開檢視）
點擊學生名冊任一列的「**診斷書**」：
- 查看學生的**原生 SVG 四軸素養雷達圖**。
- 查看 AI 正向三明治回饋：【肯定亮點】+【盲點指引】+【鷹架示範】。
- 可一鍵列印紙本頒發給學生與家長參閱。

### 3. 一鍵匯出全班 Excel 成績名冊
在成績頁右上角點擊「**匯出 Excel**」：
- 系統自動產生包含 **UTF-8 BOM (`\uFEFF`)** 之 CSV 檔案。
- **Windows Microsoft Excel 雙擊直接開啟，繁體中文 100% 絕不亂碼**。
- 完整匯出 19 項教育行政欄位（座號、姓名、總分、量尺分、基準落點、班級PR、常模PR、四層次得分與掌握率）。
